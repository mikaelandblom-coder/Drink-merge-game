Grid detection
—
Green boxes = detected cells. Too few boxes → glow is bridging a gutter: raise “gutter alpha”. Too many → raise “merge gap”. Columns are found inside each row, so a gutter that closes in one row can’t fuse that column across the whole sheet. If two items are still boxed together, they touch in the art itself — no slider fixes that.
Per-item isolation
Isolate keeps only blobs connected to the item, so a neighbour’s stem poking into the cell is dropped. “keep parts ≥” is the floor for genuinely separate pieces (a violin bow ≈ 13%, stray specks ≈ 1%). Strip shadow ignores soft alpha under the item — the game draws its own shadow.

Set
Pick a map to retune its tier chain, or start a new one. Choosing a map jumps the sprite folder to that map’s art.
The Happy Hour customer cast — the faces that queue behind the horizon. Pure art: no r, vis or hitbox, since a customer is never a physics body. Click art in the sprite folder to add a face, drag to reorder, ✕ to drop one.

Order is cosmetic — the game picks a face at random per arrival — but the cast size is not: more faces = more variety, and it is derived from this list, so adding one here is the entire change.

New faces come from the Extract tab: run a customer sheet through it, save the PNGs into shared/, then add them here.
r — the tier’s size step. The game draws each sprite at height r·2.4·vis, so the source PNG’s pixel size is irrelevant: never pre-scale the art.
vis — rescales one item visually. Physics is untouched.

Reset r ladder re-spaces r evenly 15 → 71 across the chain. It’s a starting point for a NEW chain — the shipped maps use hand-tuned ladders, so pressing it on one of those will change its tier sizes. Reordering does not do this: r belongs to the slot, so a drag re-assigns the chain’s existing values smallest → largest and a tuned ladder survives untouched.
Auto-fit vis sets every vis so each item takes up the same on-screen area as a typical sprite of its tier — the fix for wide art that would otherwise render huge.
Both buttons act on all tiers and overwrite anything you typed or dragged by hand.

⚠ If an item already has a traced capsule hitbox, changing vis means re-tracing it in the hitbox editor.
